# 项目架构目录说明

本文档记录 `smart-trip` 当前目录结构、模块职责和关键文件用途。

## 1. 根目录

```text
smart-trip/
├── backend/
├── frontend/
├── skills/
├── deploy/
├── doc/
├── README.md
├── docker-compose.yml
├── .env
├── .env.production.example
├── .dockerignore
└── .gitignore
```

| 路径 | 说明 |
|---|---|
| `backend/` | FastAPI 后端服务，包含规划链路、RAG、Memory、Skill、Agent、SQLite、数据脚本和测试。 |
| `frontend/` | Vue 3 + Vite 前端，包含用户视图和开发调试视图。 |
| `skills/` | 业务 Skill 定义与执行脚本，供后端按语义选择和沙箱调用。 |
| `deploy/` | Nginx、FRP 和本地部署辅助配置。 |
| `doc/` | 项目文档。 |
| `README.md` | 项目简介、能力说明、配置项和启动方式。 |
| `docker-compose.yml` | 后端和前端容器编排配置。 |
| `.env` | 根目录本地环境变量，不应提交真实密钥。 |
| `.env.production.example` | 生产环境变量示例。 |
| `.dockerignore` | Docker 构建忽略规则。 |
| `.gitignore` | Git 忽略规则。 |

| `backend/.env.example` | 后端环境变量示例。 |

## 3. 后端源码 `backend/app/`

```text
backend/app/
├── main.py
├── api/
├── core/
├── orchestration/
├── knowledge/
└── capabilities/
```

| 路径 | 说明 |
|---|---|
| `main.py` | FastAPI 应用入口，初始化配置、数据库、服务实例、静态资源和 API 路由。 |
| `api/` | HTTP 接入层。 |
| `core/` | 基础设施层，包含配置、路径、数据库和 Pydantic schema。 |
| `orchestration/` | 业务编排层，包含任务路由、Workflow、Agent、Context 和 Memory。 |
| `knowledge/` | 知识层，包含 RAG、检索服务和知识图谱。 |
| `capabilities/` | 能力层，包含 Skill、Sandbox、LLM、地图、图片生成、外部集成和本地数据引擎。 |

## 6. 编排层 `backend/app/orchestration/`

```text
backend/app/orchestration/
├── planning/
├── workflow/
├── agents/
├── context/
└── memory/
```

### `planning/`

| 文件 | 说明 |
|---|---|
| `planner_service.py` | 旅行规划主服务，持有任务路由、槽位抽取、会话恢复、Memory、RAG、Skill、Agent、响应生成和持久化依赖。 |
| `task_router.py` | 判断请求类型，例如轻量咨询、天气问答、景点推荐、完整规划、追问调整和澄清请求。 |
| `slot_extractor.py` | 抽取目的地、天数、预算、节奏、住宿偏好、餐饮偏好和排除景点。 |
| `revision_intent.py` | 识别用户是否在上一轮方案基础上修改预算、酒店、路线、偏好或排除项。 |

### `workflow/`

| 文件 | 说明 |
|---|---|
| `graph.py` | LangGraph 工作流定义，声明节点顺序和条件分支。 |
| `state.py` | `TripPlanningState` 共享状态定义。 |
| `trace.py` | 工作流阶段追踪记录工具。 |
| `reviewer.py` | 结构化方案校验与局部修复，处理排除景点、住宿缺失、预算超限和天数不一致等问题。 |
| `nodes/input_nodes.py` | 输入处理、任务画像、槽位合并和澄清响应。 |
| `nodes/context_nodes.py` | Memory 加载、RAG 检索和 Context 组装。 |
| `nodes/execution_nodes.py` | Skill 执行、方案校验和修复。 |
| `nodes/agent_nodes.py` | Planner、Retriever、Executor、Reviewer Agent 的 LangGraph 节点适配。 |
| `nodes/response_nodes.py` | 咨询响应、规划响应、LLM 摘要、地图图片增强、Memory 写回和会话保存。 |

### `agents/`

| 文件 | 说明 |
|---|---|
| `base.py` | Agent 输出结构和通用工具函数。 |
| `agent_service.py` | 多 Agent 调用门面。 |
| `planner_agent.py` | 需求拆解和任务分配。 |
| `retriever_agent.py` | 汇总 RAG 文档和工具结果。 |
| `executor_agent.py` | 生成结构化旅行方案。 |
| `reviewer_agent.py` | 对候选方案做软校验和审计摘要。 |

### `context/`

| 文件 | 说明 |
|---|---|
| `context_assembler.py` | 组装模型可用上下文，包括系统角色、用户请求、结构化约束、Memory、RAG、工具结果和 Agent 输出。 |
| `session_context_service.py` | 从历史运行记录恢复当前会话的基线约束、主方案和最近交互。 |

### `memory/`

| 文件 | 说明 |
|---|---|
| `memory_service.py` | 长期 Memory 的读取、写入和更新。 |
| `memory_injection_service.py` | 根据当前任务筛选相关记忆并生成注入摘要。 |
| `memory_extractor.py` | 从用户表达和结构化约束中抽取可保存偏好。 |
| `preference_profile.py` | 偏好类型定义、归一化和标签映射。 |

## 7. 知识层 `backend/app/knowledge/`

```text
backend/app/knowledge/
├── rag/
├── retrieval/
└── graph/
```

### `rag/`

| 文件 | 说明 |
|---|---|
| `bootstrap.py` | RAG 启动准备，确保 Markdown 语料、chunk manifest、BM25 索引和可选向量索引存在。 |
| `types.py` | RAG 数据类型定义。 |
| `tokenizer.py` | 中英文 token 切分。 |
| `corpus_builder.py` | Markdown 语料解析、frontmatter 读取、标题切片和 metadata 生成。 |
| `corpus_loader.py` | 加载 chunk manifest 和索引数据。 |
| `indexer.py` | BM25 索引构建。 |
| `embedding_client.py` | OpenAI-compatible Embedding 客户端。 |
| `vector_index.py` | 本地向量索引构建和读取。 |
| `retriever.py` | 本地 RAG 检索器，执行城市过滤、BM25、向量相似度、hybrid score、业务重排和 topic 去重。 |

### `retrieval/`

| 文件 | 说明 |
|---|---|
| `query_rewrite.py` | 基于目的地、天数、预算、节奏、偏好和原始输入生成检索 query。 |
| `retrieval_service.py` | RAG 服务入口，调用检索器并返回命中文档、检索步骤、ranking signals 和可注入知识。 |

### `graph/`

| 文件 | 说明 |
|---|---|
| `loader.py` | 从 Obsidian Markdown vault 加载图谱节点和边。 |
| `store.py` | SQLite 图谱存储。 |
| `service.py` | 图谱扩展服务，用于景点别名、关联点位和排除项扩展。 |

## 18. 维护规则

| 场景 | 位置 |
|---|---|
| 新增 HTTP 接口 | `backend/app/api/` |
| 新增配置、路径、数据库、schema | `backend/app/core/` |
| 新增任务路由、状态恢复、Memory、Context、Workflow、Agent | `backend/app/orchestration/` |
| 新增 RAG、Retrieval、知识图谱 | `backend/app/knowledge/` |
| 新增模型调用、工具调用、外部集成、图片生成、地图展示、本地能力引擎 | `backend/app/capabilities/` |
| 新增业务 Skill | `skills/public/<skill-name>/SKILL.md` 和 `skills/public/<skill-name>/scripts/run.py` |
| 新增项目文档 | `doc/` |

不要提交真实 API Key、SQLite 运行库、生成图片大文件、`node_modules/`、`dist/` 或缓存目录。
